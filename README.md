# 👩‍💻 Student Management System (Python)

##  Description
This is a simple desktop application developed using Python.  
It allows managing student/intern data with a graphical interface (Tkinter) and storing/exporting data in Excel files.

---

## Technologies Used
- Python  
- Tkinter (GUI)  
- Excel (openpyxl)

---

##  Features
- Add new student/intern  
- Edit existing data  
- Delete records  
- Display list of students  
- Export data to Excel file  
- Simple and user-friendly interface
